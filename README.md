## 📖 Описание

Этот проект - увлекательная игра в стиле Pokemon Go, реализованная как Telegram бот. Исследуйте виртуальный мир, ловите покемонов и развивайте свою коллекцию!

## ✨ Возможности

- 🎯 **Поиск покемонов** рандомное их выпадение с разными шансами  
- 🏆 **Коллекционирование** различных видов покемонов
- 📊 **Статистика игрока** и прогресс
- 🎮 **Интерактивные команды** для взаимодействия с игрой, и разные захватывающие битвы с друзьями 
- 📍 **Система** для исследования самих покемонов и почувствовать жизнь в битвах

## 🚀 Как начать играть

1. **Найдите бота в Telegram**: [@main_pyschool_bot](https://t.me/main_pyschool_bot)
2. **Отправьте команду**: `/start` или `/go` 
3. **Начните исследовать**: используйте команды для поиска покемонов!

## 🎯 Основные команды

| Команда | Описание |
|---------|-----------|
| `/start` | Начать игру |
| `/info` | Найти покемона и посмотреть характеристики |
| `/heal` | Лечи лучшего друга |
| `/attack` | Атакуй других что бы выжить |
| `/levelup` | Поднимай свой уровень |

## 🛠 Технологии

- **Python 3** - основной язык программирования
- **python-telegram-bot** - работа с Telegram API
- **JSON SERVER** - база данных для покемонов
- **Виртуальное окружение** - изоляция зависимостей

## 📁 Структура проекта

## 🎮 Установка и запуск (для разработчиков)

```bash
# Клонировать репозиторий
git clone https://github.com/Kaisar-salam/Python2_M1L4_pokemon_go.git

# Перейти в директорию проекта
cd Python2_M1L4_pokemon_go

# Установить зависимости
pip install -r requirements.txt

# Запустить бота
python main.py
```
