## 📖 Описание

Этот проект - увлекательная игра в стиле Pokemon Go, реализованная как Telegram бот. Исследуйте виртуальный мир, ловите покемонов и развивайте свою коллекцию!

## ✨ Возможности

- 🎯 **Поиск покемонов** в разных локациях
- 🏆 **Коллекционирование** различных видов покемонов
- 📊 **Статистика игрока** и прогресс
- 🎮 **Интерактивные команды** для взаимодействия с игрой
- 📍 **Система локаций** для исследования

## 🚀 Как начать играть

1. **Найдите бота в Telegram**: [@YourPokemonGoBot](https://t.me/YourPokemonGoBot)
2. **Отправьте команду**: `/start`
3. **Начните исследовать**: используйте команды для поиска покемонов!

## 🎯 Основные команды

| Команда | Описание |
|---------|-----------|
| `/start` | Начать игру |
| `/hunt` | Найти покемона |
| `/mypokemon` | Моя коллекция |
| `/stats` | Статистика игрока |
| `/help` | Помощь по командам |

## 🛠 Технологии

- **Python 3** - основной язык программиения
- **python-telegram-bot** - работа с Telegram API
- **SQLite/PostgreSQL** - база данных игроков и покемонов
- **Виртуальное окружение** - изоляция зависимостей
